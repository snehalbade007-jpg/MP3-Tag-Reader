MP3 TAG READER

1. Project Overview

The MP3 Tag Reader is a C programming project developed to read and display metadata information from MP3 audio files using ID3 tags.

2. Project Features

- Read MP3 audio files.
- Extract ID3 tag information.
- Display song title.
- Display artist name.
- Display album name.
- Display year and genre.

3. Technologies & Concepts Used

- Programming Language: Advanced C
- File Handling
- Structures
- Pointers
- String Handling

4. Project Description

This project uses file handling concepts in C to read MP3 file metadata. It extracts information stored in ID3 tags and displays the details in a readable format.
